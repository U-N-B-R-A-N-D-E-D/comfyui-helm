# Changelog

## 0.4.0 (unreleased)

The nodes and templates now deliver the product promise: one slider moves one idea, no prompt rewrite.

- **New `Helm · Dial` (`HelmDial`).** Pick an idea by its human name, move `amount` 0-1. Amount maps to
  `0 .. safe_max` read from the axis file, so there is no strength, norm or block to know. It reuses
  `HelmApply`'s hook. An axis made for another model is refused with a plain message. The menu lists
  *Essentials* (only axes this repo's own benchmark shows hold, from `axes_catalog.json`, and only when
  the axis file is on disk) and *Custom* (everything else). `web/helm_axes.js` refreshes the menu, and
  `/helm/axes` now also returns the `dial` entries.
- **New `Helm · Make Axis` (`HelmMakeAxis`).** Two prompts (with the idea / without the idea) + model, clip,
  latent, name, steps. Runs both contrast passes inside one execution with the same hook machinery as
  `HelmCollect`, subtracts the means exactly like `HelmVector`, and saves a self-describing axis. Its
  `safe_max` is a conservative *estimate* (0.5% of the activation norm), recorded as such, not verified.
- **Recategorized.** Collect, Vector, Apply, Probe and Probe Report moved to `Helm/Lab` with display names that
  say what they are for ("Helm Lab · Record activations", ...). Class names are unchanged: existing
  workflows, including every `HelmApply` graph, load and run as before.
- **Exactly three starter templates**, flat graphs with the Dial on the canvas and a Before | After built
  from core nodes only: "Helm 1. Start here (Z-Image)", "Helm 2. Video (MiniMax H3)",
  "Helm 3. Make your own axis". ComfyUI shows a custom node's template by its file name, so the file name is
  the title; the card thumbnail is `<file name>.jpg` (square, no metadata). Templates are generated by
  `tools/build_templates.py`, thumbnails by `tools/render_previews.py`.
- **Template and node polish (see `docs/UX-NOTES.md`).** `MarkdownNote` instead of `Note`, the three steps first
  (top-left); colours mean one thing (green you edit, orange Helm, grey leave alone, blue result), and Helm nodes
  take the same colours when added from search; large numbered group titles; the plumbing collapsed to one-line
  pills so a template, which ComfyUI always fits to the window, opens above the zoom where nodes become empty boxes.
  Tooltips on every input and a description on every node; search aliases; node help for Dial and Make Axis
  (`web/docs/`); a live caption under the Dial's slider ("Light angle (raking) at 60%") and the same line in the log.
- **Menu: Essentials by visible impact, new Subtle section.** Volumetric light beams, surface reflections and motion
  blur hold in the benchmark but show no visible effect in our renders, so they moved from Essentials to *Subtle*.
  New Dials start on *Light angle (raking)*.
- Older templates moved to `example_workflows/legacy/` (the duplicate `z_image_helm.json` was removed); their
  notes were rewritten in plain language.
- Removed a text-filter-bypass LoRA group and loader from the Krea 2 workflows (UI and API format).
- Ships seven more Z-Image axes that hold in the benchmark (tensors unchanged; header gained `safe_max` and `safe_max_source`), hashes in `docs/AXES.md`. Template 1 defaults to *Light angle (raking)*.
- Template thumbnails 1 and 2 and per-axis before/after thumbnails (`web/previews/`, exposed as `preview` by `/helm/axes`) are real Helm renders within each axis' safe range, labelled "Before" and "After (Amount 1.0)"; the technical numbers and provenance are in `docs/AXES.md`. Everything in the pack is English, enforced by `tests/test_language.py`.
- Tests: 84 -> 211 (210 run everywhere; 1 optional check needs `COMFYUI_DIR`). New: Dial mapping and mismatch errors, Make Axis equals Collect + Vector,
  template structure, core node types).

## 0.3.11 — 2026-10-30

- Krea2 and LTX templates no longer point at the shipped H3 `mood` axis; they
  use explicit `krea2_axis` / `ltx_axis` build-first placeholders.
- Added `tests/test_workflow_axes.py`: every `HelmApply` in a shipped workflow
  must use a calibrated axis with the right dimension, or a declared placeholder.
- `strength=0` is now a byte-exact passthrough in `push`, `norm` and `clamp`.
- `HelmApply` refuses an axis whose dimension does not match the calibrated model
  before sampling, with an actionable error.
- Added the ComfyUI `axis library` picker from `/helm/axes`; axes without
  `safe_max` now warn instead of running silently unclamped.
- H3 calibration max aligned with the shipped `safe_max: 0.3`; a per-axis
  `safe_max` is authoritative over the model-level band.
- Removed hard-coded private media paths from the study generator; use
  `HELM_MEDIA_ROOT` / `HELM_FONT_PATH` instead.
- 84 tests.

## 0.3.10 — 2026-10-27

- Publish hygiene: dev-only files (`tests/`, `docs/`, `study/`, `.github/`,
  demo images) are excluded from the Registry package via `.comfyignore`.
- Replaced a test-only dynamic-import call with a normal module reference.
  It triggered a false-positive `python_bytecode_manipulation` flag; no runtime
  code changed.
- Added a publish-hygiene regression test so dev-only paths and dynamic imports
  cannot silently return to the package.

## 0.3.9 — 2026-10-19

- `HelmApply` gains optional `mask_offset` for packed sequences (Z-Image: 32
  text/cond rows before 4096 spatial tokens; H3: rows before the video slice).
- Per-render provenance index for the 2026-10-19 window
  (`docs/data/evolution-20261019/`): 385 jobs, output and graph hashes.
- Disclosed the post-hoc quality ceiling: **10/53** primary push holds,
  **7/53** with saturation <= 0.5 and edge <= 2x baseline (`strict_push`).
- Z-Image room-density axis: `safe_max` corrected to **0.25** (wash at 0.5);
  the example workflow uses 0.25.
- `grid` tooltip matches the code (explicit, never inferred); public docs no
  longer reference private paths.
- Masks documented as injection-only: the delta is zero outside the mask, but
  attention propagates the visible change.
